## How I Work

- **Edge-first** — if it can run on Cloudflare Workers, it doesn't go on a server
- **Security-aware by default** — auth hardening, CSRF, rate limiting, and soft-delete on every feature
- **AI as infrastructure** — LLMs wired into data pipelines and tooling, not just chat boxes
- **Single-pass delivery** — ship complete features, not MVPs requiring 3 follow-up PRs
